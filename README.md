# Dynamic PHP & MySQL Portfolio

A responsive, database-driven developer portfolio built using PHP and MySQL. It dynamically fetches project records and displays them in a modern card layout.

## Features
- **Dynamic Content Fetching:** Reads project details directly from a MySQL database.
- **Form Submission Handling:** Allows adding new project entries.
- **Custom Port Configuration:** Configured for custom MySQL environments (Port 3307).

## Tech Stack
- **Backend:** PHP (MySQLi)
- **Database:** MySQL / MariaDB
- **Frontend:** HTML5, CSS3
